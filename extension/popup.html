Cầu nối an toàn đưa ngữ cảnh code từ ứng dụng Desktop sang tài khoản Gemini Web của bạn trên Google Chrome hoặc Microsoft Edge mà không cần API key.

Mã kết nối (Pairing JSON)
Chưa kết nối
3 bước đơn giản cho người mới
1 Bấm "Copy pairing JSON" trong tab Bridge của Studio
2 Bấm "Tự động dán" hoặc Ctrl+V vào ô trên rồi bấm "Lưu & Kết nối"
3 Mở Gemini Web, đăng nhập và giữ tab đó mở
