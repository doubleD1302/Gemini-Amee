1 Chuẩn bị trong 2 phút (Chỉ làm 1 lần duy nhất)
Cài đặt Node.js (phiên bản 22 LTS trở lên)

Node.js là phần mềm chạy nền giúp giao diện Studio hoạt động trên máy tính của bạn. Nếu máy bạn chưa có, hãy tải bản cài đặt Windows tại link dưới (bấm Next theo mặc định là xong):

Tải Node.js chính thức (nodejs.org) ↗
Khởi động ứng dụng bằng file start-windows.bat

Sau khi cài Node.js, chỉ cần nhấp đúp vào file start-windows.bat trong thư mục này. Lần đầu tiên chạy, máy sẽ tự động tải các thư viện cần thiết trong khoảng 1-2 phút, sau đó cửa sổ Studio sẽ tự động mở lên!

💡 Mẹo sửa lỗi nhanh: Nếu tải bị lỗi do mạng yếu, hãy nhấp đúp vào file repair-windows.bat để hệ thống tự động sửa chữa.
2 Chọn cách trò chuyện với Gemini

Extension hoạt động hoàn hảo trên cả Microsoft Edge (có sẵn trên Windows) và Google Chrome:

Bước 2.1: Mở thư mục Extension

Trong ứng dụng Studio, chọn tab Bridge ở thanh bên phải rồi bấm "Mở thư mục Extension trên máy".

Bước 2.2A: Cài vào Microsoft Edge (Nếu bạn dùng Edge trên Windows)

1. Mở Microsoft Edge, gõ edge://extensions vào thanh địa chỉ.
2. Bật công tắc "Chế độ dành cho nhà phát triển" (Developer mode) ở cột menu bên trái.
3. Bấm nút "Tải phần mở rộng chưa giải nén" (Load unpacked) ở trên đầu rồi chọn thư mục extension.

Bước 2.2B: Cài vào Google Chrome (Nếu bạn dùng Chrome)

1. Mở Google Chrome, gõ chrome://extensions vào thanh địa chỉ.
2. Bật công tắc "Developer mode" ở góc trên bên phải.
3. Bấm nút "Load unpacked" (Tải tiện ích đã giải nén) rồi chọn thư mục extension.

Bước 2.3: Ghép nối trong 1 click

Trong Studio, bấm nút "Copy mã kết nối (Pairing JSON)". Sau đó bấm vào biểu tượng Extension hình ngôi sao ✦ trên thanh công cụ trình duyệt (Edge hoặc Chrome), chọn "⚡ Tự động dán" rồi bấm "Lưu & Kết nối".

Bước 2.4: Mở tab Gemini Web

Mở trang web https://gemini.google.com/app bằng tài khoản Google của bạn trên Edge hoặc Chrome và giữ tab đó mở. Bạn đã hoàn thành kết nối!

Nếu bạn không muốn cài Extension hoặc dùng máy tính công ty bị chặn tiện ích, bạn vẫn có thể dùng Studio cực kỳ thuận tiện với 3 bước Copy - Dán:

1. Nhập câu hỏi trong Studio

Studio sẽ tự động tìm kiếm tối đa 18 file mã nguồn quan trọng nhất liên quan đến câu hỏi của bạn và gộp thành một đoạn văn bản hoàn chỉnh.

2. Bấm Gửi (hoặc Soạn context)

Khi Extension chưa kết nối, Studio sẽ tự động copy toàn bộ câu hỏi và mã nguồn vào bộ nhớ tạm (Clipboard) của bạn!

3. Dán vào Gemini Web và đưa kết quả về Studio

Mở tab gemini.google.com, bấm Ctrl+V để hỏi. Sau khi Gemini trả lời xong, bạn copy kết quả, quay lại Studio bấm "Dán câu trả lời thủ công" (hoặc bấm ⚡ Dán nhanh từ bộ nhớ tạm). Câu trả lời sẽ hiện ra với định dạng code đẹp mắt!

3 Mẹo đặt câu hỏi thông minh cho người không chuyên

Bạn không cần biết lập trình! Hãy sao chép những câu hỏi mẫu dưới đây để nhờ Gemini phân tích dự án giúp bạn:

1. Hiểu tổng quan: "Hãy giải thích cho tôi project này có chức năng gì, giải quyết bài toán nào và dành cho đối tượng người dùng nào bằng ngôn ngữ bình dân, dễ hiểu nhất."

2. Hướng dẫn chạy thử: "Hãy hướng dẫn tôi cách cài đặt các công cụ và các lệnh để chạy thử ứng dụng này trên máy tính Windows từng bước một từ A đến Z."

3. Kiểm tra chất lượng: "Phân tích các rủi ro, lỗi tiềm ẩn, vấn đề bảo mật và những điểm code chưa tốt trong project này. Đưa ra giải pháp sửa cụ thể."

4. Soạn tài liệu: "Viết cho tôi một bản hướng dẫn sử dụng (User Manual) chi tiết cho dự án này để người dùng thông thường biết cách thao tác."

? Giải đáp thắc mắc thường gặp (FAQ)
1. Code của tôi có bị gửi lên mạng hay bị ai xem trộm không?
Dữ liệu code chỉ được gửi trực tiếp đến tài khoản Gemini Web chính chủ của bạn tại Google khi bạn gửi câu hỏi. Ngoài Google ra, không có bất kỳ máy chủ bên thứ ba nào nhận dữ liệu này. Cầu nối giữa Studio và Extension chỉ chạy cục bộ bên trong máy tính của bạn (địa chỉ 127.0.0.1).
2. Tôi có cần phải mua tài khoản trả phí hay đăng ký API key không?
Hoàn toàn không! Studio tận dụng giao diện Gemini Web miễn phí mà bạn thường dùng hằng ngày trên trình duyệt, không cần bất kỳ API key hay thẻ tín dụng nào.
3. Nếu lỡ tay tắt cửa sổ đen (Command Prompt) thì sao?
Cửa sổ đen là nơi chạy máy chủ cục bộ cho Studio. Nếu bạn lỡ tắt, ứng dụng Studio cũng sẽ đóng lại. Muốn dùng lại, bạn chỉ cần nhấp đúp lại file start-windows.bat.
4. Các file mật khẩu (.env, credentials) có bị gửi đi không?
Studio đã tích hợp sẵn bộ lọc an ninh: tự động bỏ qua toàn bộ file bí mật (.env, key, id_rsa, database password...) cũng như các thư mục nặng như node_modules, .git để đảm bảo an toàn tối đa cho bạn.
